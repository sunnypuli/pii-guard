# Example: Customer CSV analysis with PII scrubbed

## Scenario

You have a CSV of customer data with Aadhaar, PAN, email, and mobile.
You want Claude to analyse churn patterns — but not see real PII.

## Files

- `customers.csv` — sample data (fake PII for demo)
- `customers.safe.csv` — tokenized version (generated by piiwall)

## Workflow

```bash
# 1. Scan first to see what PII exists
piiwall scan customers.csv --show-values

# 2. Tokenize
piiwall tokenize customers.csv -p dpdp

# 3. Analyse the safe version with Claude Code
# (Claude only sees [EMAIL_1], [AADHAAR_1], etc.)
claude "Analyse customers.safe.csv for churn patterns"

# 4. If you need real values in the output, detokenize
piiwall detokenize result.txt --session ~/.piiwall/sessions/piiwall-<timestamp>.json
```
